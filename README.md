# 🏋️ Fit-Log

**Fit-Log** is a fitness tracking web application designed to help users manage and track their workouts in an organized way. Users can explore workouts, add them to their plan, save workouts for later, and manage their fitness activities through a simple and responsive interface.

## 🚀 Technologies Used

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **Context API**
* **Next.js App Router**
* **React Icons**
* **React Toastify**
* **JSON Server / REST API**

## ✨ Key Features

### 1. 🏃 Workout Management

Users can browse available workouts and view detailed information about different exercises.

### 2. 📋 Personal Workout Plan

Users can add workouts to their personal plan and remove them whenever they want.

### 3. 🔖 Save for Later

Users can save their favorite workouts for later and manage their saved workout list.

### 4. 🔔 Toast Notifications

Interactive toast notifications provide users with instant feedback when performing actions such as adding, removing, or saving workouts.

### 5. 📱 Responsive Design

The application is designed to work smoothly across desktop, tablet, and mobile devices.

## 📂 Project Purpose

The main goal of Fit-Log is to practice building a real-world fitness application using modern React and Next.js concepts such as:

* Server and Client Components
* Context API
* TypeScript
* API data fetching
* Dynamic routing
* Loading states
* Reusable components
* Responsive UI
